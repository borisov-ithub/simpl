# Simpl — справочник по языку

Версия 3.1.0.

## 1. Общее

Simpl — учебный язык программирования. Синтаксис вдохновлён Lua, семантика — выражениями вместо инструкций (как в Rust и Elixir).

Каждая конструкция в Simpl — **выражение**, у которого есть значение. Программа — это блок выражений, разделённых переводом строки. Значение программы — значение последнего выражения.

Файлы имеют расширение `.spl`.

## 2. Запуск

```
simpl [опции] [файл.spl]
```

### Опции

| Опция | Что делает |
|---|---|
| `-h`, `--help` | Показать справку |
| `-v`, `--version` | Показать версию |
| `-c`, `--check` | Проверить синтаксис файла без выполнения |
| `-r`, `--repl` | Интерактивная среда |

### Примеры

```
simpl program.spl
simpl --check program.spl
simpl -v
```

## 3. Лексика

### 3.1 Комментарии

```
-- до конца строки
```

### 3.2 Идентификаторы

Начинаются с буквы или `_`, продолжаются буквами, цифрами и `_`.

### 3.3 Числа

Десятичные, двоичные, восьмеричные, шестнадцатеричные. Допускается `_` как разделитель разрядов и `.` для дробной части (только в десятичных). Экспоненциальная запись `e`/`E` — только в десятичных:

```
42
1_000_000
3.14

1e20    -- 10^20
1.5e-3  -- 0.0015
2E10    -- 2 * 10^10
1_000e3 -- 1_000_000

0b101010        -- 42
0B101010        -- 42
0o52            -- 42
0O52            -- 42
0xFF            -- 255
0Xff            -- 255
0xFF_FF         -- 65535
```

Префиксы `0b`/`0o`/`0x` — в любом регистре. Hex-цифры — `0-9`, `a-f`, `A-F`. Экспонента — `e`/`E`, опционально `+`/`-`, минимум одна цифра.

### 3.4 Строки

Строки в **двойных** или **одинарных** кавычках. Внутри двойных можно писать `"` без экранирования только через `\"`; внутри одинарных — `'` через `\'`. Кросс-экранирование не нужно: `'он сказал "привет"'` работает.

Escape-последовательности: `\n`, `\t`, `\"`, `\'`, `\\`, `\$`.

```
"Привет"
'Привет'
"Строка с \"кавычками\""
'он сказал "привет"'
```

**Интерполяция:** `$(выражение)` внутри строки подставляет результат выражения. Вложенность `$(...)` внутри `$(...)` не поддерживается; скобки внутри `$(...)` балансируются.

```
"Сумма: $(2 + 2)"        -- "Сумма: 4"
"Привет, $(name)!"
"Результат: $(f(1, 2))"
```

### 3.5 Ключевые слова

```
let  if  elseif  else  then  end
for  in  do  loop  break  continue
match  return  and  or  not
true  false  nil
echo  echo.
use  as import type
```

## 4. Переменные и мутабельность

### 4.1 Объявление

```
let x = 1        -- неизменяемая
let ^y = 1       -- изменяемая
```

`^` перед именем — маркер мутабельности **переменной**. Присваивание переменной без `^` запрещено:

```
let ^y = 1
^y = 2           -- ок
y = 3            -- ошибка: присваивание требует ^
```

Присваивание неизменяемой переменной через `^` — ошибка выполнения:

```
let x = 1
^x = 2           -- ошибка: переменная неизменяемая
```

### 4.2 Присваивание полям struct

Поля struct **мутабельны всегда**, независимо от того, как объявлена переменная. `let` защищает только переменную от переприсваивания, но не содержимое struct:

```
let s = { a = 1 }
s.a = 10         -- ок: меняем поле, а не переменную
s["a"] = 20      -- ок
s.a.b = 30       -- ок, если s.a — struct
s = { a = 2 }    -- ошибка: переменная неизменяема

let ^t = { a = 1 }
^t = { a = 2 }   -- ок: переменная изменяема
```

Для присваивания полю/индексу `^` не нужен. Для присваивания переменной — нужен.

### 4.3 Область видимости

Блок создаёт новую область видимости: тело функции, тело `if`-ветки, тело цикла, тело `match`-ветки. Переменные внешней области видны внутри, но не наоборот.

### 4.4 Деструктуризация

```
let (a, b) = (1, 2)
let (^x, y) = (10, 20)
```

Элементы кортежа привязываются к именам по порядку. Количество имён и элементов должно совпадать.

## 5. Типы значений

| Тип | Пример | Примечание |
|---|---|---|
| `nil` | `nil` | Отсутствие значения |
| `number` | `42`, `3.14` | Одно число с плавающей точкой |
| `string` | `"abc"` | UTF-8, длина в символах |
| `bool` | `true`, `false` | |
| `tuple` | `(1, "a", true)` | Индексация с 0, фиксированная длина |
| `struct` | `{ name = "Аня" }` | Ассоциативный, ключи — строки внутри |
| `function` | `let f (x) = x end` | |

### 5.1 Кортежи

```
let t = (1, "два", true)
t[0]              -- 1
t[2]              -- true
len(t)            -- 3
```

Пустой кортеж: `()`. Кортеж из одного элемента: `(x,)` — запятая обязательна. Кортеж **неизменяем**: `t[0] = 1` — ошибка.

### 5.2 Struct

```
let person = { name = "Аня", age = 12 }
person.name       -- "Аня"
person["age"]     -- 12
person[1]         -- доступ по числовому ключу
```

Автоключи, если элементы перечислены без имён:

```
let arr = { "a", "b", "c" }
arr[0]            -- "a"
arr["0"]          -- "a" (то же самое)
```

**Внутри ключи всегда строки.** Числовые ключи (`0`, `1`, `2`, ...) при извлечении через `struct.keys`, `struct.entries`, `for k, v in` возвращаются как **числа**. Строковые — как строки. Доступ `s[0]` и `s["0"]` — одно и то же.

**Автоключи.** Если элемент struct-литерала перечислен без имени, ему присваивается ключ `max(числовые ключи) + 1`, или `0`, если числовых ключей ещё нет:

```
{ "a", "b" }             -- { 0="a", 1="b" }
{ 1="a", "b" }           -- { 1="a", 2="b" }
{ 5="a", "b", "c" }      -- { 5="a", 6="b", 7="c" }
{ x=1, "a" }             -- { x=1, 0="a" }
{ -1="a", "b" }          -- { -1="a", 0="b" }
```

При конфликте ключей (явный ключ пересекается с автоключом или другим явным ключом) — **перезапись** (последняя запись выигрывает).

**Порядок ключей.** В `display()`, `for k, v in`, `struct.keys`, `struct.values`, `struct.entries` — числовые ключи сортируются как числа, строковые — лексикографически. Числовые идут раньше строковых.

### 5.3 Вложенные struct

```
let s = { a = { b = 1 } }
s.a.b            -- 1
s.a.b = 5        -- ок: меняем вложенное поле
```

## 6. Операторы

От низкого приоритета к высокому:

| Приоритет | Операторы | Ассоциативность |
|---|---|---|
| 1 (низший) | `a if cond else b` | право |
| 2 | `$` (конвейер) | лево |
| 3 | `or` (логическое) | лево |
| 4 | `and` (логическое) | лево |
| 5 | `not` (логическое) | унарный |
| 6 | `\|` (побитовое ИЛИ) | лево |
| 7 | `xor` (побитовое XOR) | лево |
| 8 | `&` (побитовое И) | лево |
| 9 | `==` `!=` `<` `<=` `>` `>=` | лево |
| 10 | `<<` `>>` (сдвиги) | лево |
| 11 | `++` `..` | лево |
| 12 | `+` `-` | лево |
| 13 | `*` `/` `%` | лево |
| 14 | унарный `-`, `~`, `type` | |
| 15 (высший) | `()` `[]` `.` | лево |

### 6.1 Арифметика

`+`, `-`, `*`, `/`, `%` — только для чисел. Деление или остаток на ноль — ошибка.

### 6.2 Сравнение

`==`, `!=` работают для всех типов. `<`, `<=`, `>`, `>=` — только для чисел.

### 6.3 Логические

`and`, `or`, `not` — короткое замыкание. `nil` и `false` — ложны, всё остальное — истинно.

### 6.4 Конкатенация

`++` соединяет строки. Не-строки преобразуются через `display()`:

```
"a" ++ 1 ++ true       -- "a1true"
```

### 6.5 Тернарник

```
a if cond else b
```

Сахар над `if`. Цепочка без скобок запрещена — ошибка парсера:

```
1 if a else 2 if b else 3             -- ошибка
1 if a else (2 if b else 3)           -- ок
```

## 6.6 Конвейер (`$`)

`a $ f` = `f(a)`. Лево-ассоциативно. Приоритет — выше тернарника, ниже `or`.

```
let inc (n) = n + 1 end
let dbl (n) = n * 2 end
let add (a, b) = a + b end

let x = 1
echo. x $ inc $ dbl $ add(10) $ inc
-- ((1+1)*2 + 10) + 1 = 13
```

**Важно**: правый операнд `$` — функция. Каррирование работает: `add(10)` — каррированная функция, `x $ add(10)` = `add(10)(x)`.

## 6.7 Композиция (`..`)

`(f .. g)(x)` = `g(f(x))`. Лево-ассоциативно. Приоритет — как `++`.

```
let inc (n) = n + 1 end
let dbl (n) = n * 2 end
let add (a, b) = a + b end

let func = inc .. dbl .. add(10) .. inc
echo. func(1)
-- inc(1)=2, dbl(2)=4, add(10)(4)=14, inc(14)=15
```

**Важно**: оба операнда `..` — функции. Каррирование работает: `add(10)` — функция.

## 6.8 `flip`

`flip(f)` — возвращает функцию с переставленными аргументами. Только для **бинарных** функций (ровно 2 обязательных параметра, без `*rest`, без default).

```
let sub (a, b) = a - b end
let rsub = flip(sub)
echo. rsub(3, 10)       -- sub(10, 3) = 10 - 3 = 7
echo. flip(sub)(1)(2)   -- sub(2, 1) = 2 - 1 = 1
```

**Ошибки**: `flip` на не-функции, на унарной/тернарной функции, на `Builtin` — ошибка.

## 6.9 Побитовые операции

Работают только с **целыми** числами в диапазоне `|n| < 2^53`. Дробные — ошибка.

| Оператор | Что делает | Пример |
|---|---|---|
| `a & b` | Побитовое И | `6 & 3` = 2 |
| `a \| b` | Побитовое ИЛИ | `6 \| 3` = 7 |
| `a xor b` | Побитовое XOR | `6 xor 3` = 5 |
| `~a` | Побитовое НЕ (дополнительный код) | `~5` = -6 |
| `a << n` | Сдвиг влево | `1 << 4` = 16 |
| `a >> n` | Арифметический сдвиг вправо | `-8 >> 1` = -4 |

**`xor`** — словом (не `^`, потому что `^` — маркер мутабельности).

**Сдвиги**: `0 <= n < 64`, иначе ошибка.

**Отличие от логических**: `and`/`or`/`not` работают с `truthy` (любые значения), `&`/`|`/`xor`/`~` — только с целыми числами.

## 7. Условия

```
if cond then expr end
if cond then expr else expr end
if cond then expr elseif cond then expr else expr end
```

`if` — выражение, возвращает значение выбранной ветки. Один `end` на всю цепочку.

## 8. Функции

### 8.1 Объявление

```
let name (params) = body end
```

### 8.2 Анонимная функция

```
\(params) = body end
```

### 8.3 Неявный возврат

Функция возвращает значение последнего выражения в теле. `return` используется для раннего выхода.

```
let f (x) = x + 1 end
let g (x) =
    if x > 0 then return "плюс" end
    "ноль"
end
```

### 8.4 Параметры

- Обычные: `let f (a, b) = ... end`.
- Со значением по умолчанию: `let f (a, b = 10) = ... end`. Параметры с default идут после параметров без default. Default вычисляется **при каждом вызове** в окружении вызова, видит предыдущие параметры.
- Сбор остальных: `let f (*rest) = ... end`. `*rest` — последний параметр, получает кортеж всех оставшихся аргументов.

```
let f (a, b = a + 1) = a + b end
f(3)          -- 7 (b = 4)
f(3, 10)      -- 13
```

### 8.5 Арность

Если аргументов меньше, чем обязательных параметров (без default и без `*`) — ошибка. Если больше, чем суммарно без `*` — ошибка.

### 8.6 Объявление метода

`target.name(params) = body end` — сахар для `target.name = \(params) = body end`. Мутирует `target` (struct).

```
let Rectangle (w, h) =
    let self = {}
    self.area = \() = w * h end
    self.perimeter() = 2 * (w + h) end
    self
end

let r = Rectangle(10, 5)
echo. r.area(), r.perimeter()
```

**Ограничения**:
- Параметры — **только имена** (`self.f(a, b) = ... end`). `*rest` и default — через `self.f = \(a, b = 1) = ... end`.
- `target` — `Var`, `Field`, `Index` (`self.a.b.f() = ...`, `arr[0].f() = ...`).

## 9. Каррирование

Функции **каррированы**: если при вызове передано меньше обязательных аргументов, чем объявлено, возвращается **новая функция** с уже привязанными аргументами.

```
let add (a, b) = a + b end

add(1, 2)      -- 3 (полный вызов)
add(1)         -- функция, ждущая b
add(1)(2)      -- 3
```

**Обязательные параметры** — без `*args` и без значения по умолчанию.

**Значения по умолчанию**: если аргументов достаточно для всех обязательных, но не хватает для параметров с default — **применяется default**, каррирования нет.

```
let g (a, b = 10) = a + b end
g(1)           -- 11 (a=1, b=10)
g(1, 2)        -- 3
g()            -- функция, ждущая a
g()(5)         -- 15 (a=5, b=10)
```

**`*args`**: параметр `*rest` не участвует в каррировании. Он забирает все «лишние» аргументы при полном вызове.

```
let h (a, *rest) = (a, rest) end
h(1)           -- (1, ())
h(1, 2, 3)     -- (1, (2, 3))
h()            -- функция, ждущая a
h()(5)         -- (5, ())
```

**Слишком много аргументов** — ошибка. Каррирование не «поглощает» лишние.

```
add(1, 2, 3)   -- ошибка: слишком много аргументов
```

**Встроенные функции не каррируются** — только объявленные через `let` или `\`.


## 10. Циклы

### 10.1 Числовой for

```
for i = 1, 10 do ... end
for i = 1, 10, 2 do ... end
for i = 10, 1, -1 do ... end
```

Границы включающие. Шаг по умолчанию `1`. Шаг `0` — ошибка.

### 10.2 Итерация по кортежу или struct

```
for v in (1, 2, 3) do ... end
for k, v in { a = 1, b = 2 } do ... end
```

По кортежу: `v` — значение, `k` (если два) — индекс. По struct: `k` — ключ (число или строка, в зависимости от ключа), `v` — значение.

### 10.3 Бесконечный цикл

```
loop
    ...
    break
end
```

### 10.4 Управление

- `break` — выйти из ближайшего цикла.
- `continue` — перейти к следующей итерации.

## 11. match

```
match value
    pattern -> body
    pattern if guard -> body
    _ -> body
end
```

`match` — выражение, возвращает значение выбранной ветки. Порядок важен: проверяется сверху вниз.

### 11.1 Паттерны

| Паттерн | Совпадение |
|---|---|
| `_` | любое значение |
| `name` | любое значение, привязывает к имени |
| `42` | число 42 |
| `"abc"` | строка "abc" |
| `true` / `false` | булево |
| `nil` | nil |
| `(p1, p2)` | кортеж из двух элементов, оба совпали |

### 11.2 Guard

```
match x
    n if n > 0 -> "плюс"
    n if n < 0 -> "минус"
    _ -> "ноль"
end
```

Guard вычисляется в окружении, где уже привязаны переменные паттерна.

## 12. echo

```
echo expr, expr, ...      -- без перевода строки
echo. expr, expr, ...     -- с переводом строки
```

Инструкция, возвращает `nil`. Аргументы печатаются через пробел. Без аргументов — ошибка парсера.

## 13. use

```
use module (*)              -- всё из модуля без префикса
use module (name1, name2)   -- только указанные имена
use module as alias         -- модуль под псевдонимом
use module as alias (name)  -- имена без префикса + модуль под псевдонимом
```

`use` действует **только на верхнем уровне файла** (вне функций, `if`, `for`, `loop`, `match`). Внутри блока — ошибка парсера.

**Семантика:**
- `use` **добавляет** имена в текущую область, не убирая ничего.
- Модуль всегда доступен по своему имени (`string.upper` работает даже после `use string (*)`).
- Конфликт имён — ошибка.
- Неизвестная библиотека или имя — ошибка.

**Примеры:**

```
use string (*)
echo. upper("abc")           -- ABC

use string (trim)
echo. trim("  hi  ")         -- hi
echo. string.upper("x")      -- X

use string as s
echo. s.upper("abc")         -- ABC

use string as s (trim)
echo. trim("  hi  ")         -- hi
echo. s.upper("x")           -- X
```

## 14. import

```
import path                     -- модуль под своим именем
import path (*)                 -- всё из файла без префикса
import path (name1, name2)      -- только указанные имена
import path as alias            -- файл под псевдонимом
import path as alias (name)     -- имена без префикса + модуль под псевдонимом
```

`import` загружает **файл** `.spl` и делает его содержимое доступным как struct. Действует **только на верхнем уровне файла** (вне функций, `if`, `for`, `loop`, `match`). Внутри блока — ошибка парсера.

### 14.1 Путь

- Относительный путь резолвится **относительно файла, в котором написан `import`**.
- `import ../file` — на уровень выше.
- `import library/file` — подкаталог. Разделитель — всегда `/`, независимо от ОС.
- Путь с пробелами — в кавычках: `import "с:/с пробелом/файл"`.
- Абсолютные пути (`/usr/...`, `с:/...`) используются как есть.
- Расширение `.spl` добавляется автоматически, если его нет. `import file` ищет `file.spl`.

### 14.2 Что попадает в модуль

**Все переменные, объявленные через `let` на верхнем уровне файла.** Встроенные библиотеки (`len`, `string`, ...) в модуль **не** попадают.

```
-- utils.spl
let add (a, b) = a + b end
let sub (a, b) = a - b end
let PI = 3.14159
```

```
-- main.spl
import utils
echo. utils.add(1, 2), utils.PI     -- 3 3.14159
```

### 14.3 Формы импорта

| Форма | Что делает |
|---|---|
| `import utils` | Модуль под именем `utils`. Доступ: `utils.add`, `utils.PI` |
| `import utils (*)` | Все имена из модуля без префикса. `add(1, 2)` работает; `utils.add` тоже |
| `import utils (add)` | Только `add` без префикса; модуль `utils` тоже доступен |
| `import utils as u` | Модуль под именем `u`. Доступ: `u.add`, `u.PI` |
| `import utils as u (add)` | `add` без префикса и модуль под `u` |

**Конфликт имён** при `(*)` или `(names)` — ошибка. **Неизвестное имя** в `(names)` — ошибка.

### 14.4 Кеш и циклы

- Один файл выполняется **один раз**, даже если импортируется из нескольких мест. Повторный `import` возвращает тот же модуль (тот же `Rc`).
- Циклический импорт (`a` импортирует `b`, `b` импортирует `a`) — **ошибка** `Циклический импорт: <путь>`. В отличие от Python, Simpl не даёт «частично инициализированный модуль».

### 14.5 Отличие от `use`

| | `use` | `import` |
|---|---|---|
| Что | встроенные библиотеки | файлы `.spl` |
| Кеш | нет (библиотеки уже в `globals`) | да (по канонизированному пути) |
| Циклы | невозможны | ошибка |
| Резолвинг | по имени в `globals` | по пути относительно текущего файла |

Синтаксис `(*)`, `(names)`, `as alias` — одинаковый.

### 14.6 argv

## argv

Глобальная переменная — кортеж строковых аргументов командной строки, переданных **после** имени файла.

```
$ simpl program.spl hello world
```

```
-- program.spl
echo. argv           -- ("hello", "world")
echo. len(argv)      -- 2
echo. argv[0]        -- "hello"
```

Если аргументов нет — `argv` — пустой кортеж `()`. В REPL `argv` всегда `()`.

**Важно**: всё после имени файла — аргументы программы, включая строки, начинающиеся с `-`. Флаги CLI (`-h`, `-v`, `-c`, `-r`) распознаются только **до** имени файла.

```
simpl program.spl -v          -- -v — аргумент программы, не флаг CLI
simpl -v program.spl          -- -v — флаг CLI, выводит версию и выходит
```

## 16. type

`type` — унарный оператор, возвращает строку с именем типа значения:

```
type 42              -- "number"
type "abc"           -- "string"
type true            -- "bool"
type nil             -- "nil"
type (1, 2)          -- "tuple"
type { a = 1 }       -- "struct"
type len             -- "function"

echo. type x         -- печатает тип x
let t = type x       -- t = "number"
```

**Приоритет** — как у унарного `-`: выше `+`, `*`, сравнений, `and`, `or`. `type x + 1` — это `(type x) + 1`.

**Совместимость**: `type(x)` работает как `type (x)` — скобки просто группируют.

**Допустимые значения**: `"nil"`, `"number"`, `"string"`, `"bool"`, `"tuple"`, `"struct"`, `"function"`.

## 24. Ошибки

### 24.1 Ошибки парсера

С указанием строки, столбца, фрагмента и подсказки. Для незакрытых конструкций — с указанием места начала:

```
Строка 3:15: ожидался 'end' для конструкции 'if', начатой в строке 2:1, но достигнут конец (встретилось: Eof).
Подсказка: у каждой 'if' должен быть парный 'end'.
```

### 24.2 Ошибки выполнения

С указанием причины и подсказки:

```
Переменная 'x' объявлена как неизменяемая (let x).
Подсказка: используйте let ^x при объявлении, если значение нужно менять.
```

### 24.3 Обработка ошибок

По умолчанию runtime-ошибка прерывает программу. `pcall` позволяет **перехватить** её.

```
let ok, result = pcall(\(x) = 10 / x end, 0)
if ok then
    echo. "Результат: ", result
else
    echo. "Ошибка: ", result      -- "Деление на ноль"
end
```

**`pcall(f, args...)`** — вызывает `f` с аргументами. Возвращает кортеж:
- `(true, result)` — если `f` завершилась успешно.
- `(false, error_message)` — если `f` упала.

**`xpcall(f, handler, args...)`** — как `pcall`, но при ошибке вызывает `handler(error_message)`. Результат `handler` становится вторым элементом `(false, handler_result)`. Если `handler` сам упал — `(false, handler_error)`.

```
let ok, msg = xpcall(
    \(x) = 10 / x end,
    \(e) = "поймано: " ++ e end,
    0
)
echo. ok, msg      -- false поймано: Деление на ноль
```

**`error(msg)`** — принудительно возбуждает ошибку. Ловится `pcall`/`xpcall`. Вне `pcall` — прерывает программу.

```
let ok, msg = pcall(\(x) =
    if x < 0 then error("отрицательное число") end
    x
end, -5)
echo. ok, msg      -- false отрицательное число
```

#### Что ловит pcall, а что нет

`pcall`/`xpcall` ловят **динамические** ошибки — те, что зависят от значений во время выполнения:

```
pcall(\(x) = 10 / x end, 0)          -- false, "Деление на ноль"
pcall(\(x) = x + "a" end, 1)          -- false, "арифметика: ..."
pcall(\(x) = error("boom") end, 1)    -- false, "boom"
```
Статические ошибки (например, "a" + 1 с литералами, 3.5 & 1, 1 << 64) ловятся чекером до выполнения — pcall их не перехватывает, потому что программа до них не доходит.


## 25. Comprehension (struct)

Создать struct из итерации:

```
{ key_expr : value_expr for var in iterable }
{ key_expr : value_expr for k, v in iterable }
{ key_expr : value_expr for var in iterable if cond }
```

**`var`** — одна переменная: значение элемента. **`k, v`** — две: ключ и значение.

`iterable` — кортеж или struct. По кортежу `k` — индекс (число), `v` — значение. По struct — `k` — ключ (число или строка, как в `for k, v in struct`), `v` — значение.

**`if cond`** — фильтр: элемент пропускается, если `cond` ложно.

**Ключи** приводятся к строкам (как везде в struct). Конфликт ключей — перезапись.

```
-- квадраты чисел 1..9
let squares = { x: x*x for x in range(1, 10) }
echo. squares[3]      -- 9
echo. squares[5]      -- 25

-- только чётные
let evens = { x: x for x in range(0, 10) if x % 2 == 0 }
echo. evens           -- { 0 = 0, 2 = 2, 4 = 4, 6 = 6, 8 = 8 }

-- по struct: ключ → значение
let person = { name = "Аня", age = 12 }
let upper = { k: k for k, v in person }
echo. upper           -- { age = age, name = name }

-- по кортежу: индекс → значение
let t = ("a", "b", "c")
let indexed = { i: v for i, v in t }
echo. indexed         -- { 0 = a, 1 = b, 2 = c }
```

**Ограничения:**
- Только один `for` (не `for x in a for y in b`).
- `:` — только в comprehension; для литерала с ключом — `=`.
- `{ a: 1 }` без `for` — ошибка парсера.

## 26. Грамматика (EBNF, упрощённо)

```ebnf
(*
  Упрощённая грамматика Simpl.
  Не отражает семантические ограничения — они перечислены в комментариях ниже.
*)

program     = { statement } ;
statement   = use | import | let | let_tuple | return | break | continue | echo | assign | expr ;

(* use и import допустимы только на верхнем уровне файла, не внутри block.
   Внутри block парсер выдаёт ошибку «только на верхнем уровне». *)
use         = "use" Ident [ "as" Ident ] "(" ( "*" | Ident { "," Ident } ) ")" ;
import      = "import" import_path [ "as" Ident ] [ "(" ( "*" | Ident { "," Ident } ) ")" ] ;
(* import_path: строка в кавычках (для путей с пробелами, абсолютных, Windows)
   или сегменты через "/". ".." — подъём на уровень выше, "." — текущая директория.
   Разделитель — всегда "/", независимо от ОС. *)
import_path = String | ( Ident | "." | ".." ) { "/" Ident } ;

(* let: либо функция ("(" params ")" "=" block "end"), либо переменная ("=" expr).
   Функция не может быть мутабельной (^), это ошибка парсера. *)
let         = "let" [ "^" ] Ident
              ( "(" params ")" "=" block "end"          -- функция
              | "=" expr ) ;                             -- переменная
(* let_tuple: деструктуризация кортежа. Каждое имя может быть ^ или без. *)
let_tuple   = "let" "(" [ "^" ] Ident { "," [ "^" ] Ident } ")" "=" expr ;
(* params: параметры функции. "*rest" — сбор остальных, должен быть последним.
   Параметры с default идут после параметров без default.
   Дубликат имени параметра — ошибка парсера. *)
params      = [ param { "," param } ] ;
param       = [ "*" ] Ident [ "=" expr ] ;

return      = "return" [ expr ] ;
(* echo без аргументов — ошибка парсера. *)
echo        = ( "echo" | "echo." ) expr { "," expr } ;

(* assign: присваивание переменной (только с ^) или полю/индексу (без ^).
   Цепочки: s.a.b = expr, s["a"]["b"] = expr. *)
assign      = "^" Ident "=" expr
            | postfix ( "." Ident | "[" expr "]" ) "=" expr ;

expr        = ternary ;
(* Тернарник: else-ветка не может начинаться с if без скобок.
   a if c1 else b if c2 else d — ошибка парсера.
   a if c1 else (b if c2 else d) — ок. *)
ternary     = pipe [ "if" pipe "else" ternary ] ;
(* Конвейер: a $ f = f(a). Лево-ассоциативно. *)
pipe        = or { "$" or } ;
or          = and { "or" and } ;
and         = not { "and" not } ;
not         = [ "not" ] comparison ;
comparison  = concat { ( "==" | "!=" | "<" | "<=" | ">" | ">=" ) concat } ;
(* concat: ++ (конкатенация строк) и .. (композиция функций) на одном уровне,
   лево-ассоциативно. *)
concat      = add { ( "++" | ".." ) add } ;
add         = mul { ( "+" | "-" ) mul } ;
mul         = unary { ( "*" | "/" | "%" ) unary } ;
(* unary: унарный минус и type — операторы с одинаковым приоритетом. *)
unary       = [ "-" | "type" ] postfix ;
postfix     = primary { "(" args ")" | "[" expr "]" | "." Ident } ;
args        = [ expr { "," expr } ] ;

primary     = Number | String | "true" | "false" | "nil"
            | Ident
            | "(" tuple_or_group ")"
            | "{" fields "}"
            | if_expr | match_expr | lambda | for_expr | loop_expr ;

(* (expr) — группировка; (expr, ...) или (expr,) — кортеж; () — пустой кортеж. *)
tuple_or_group = [ expr { "," expr } [ "," ] ] ;

(* fields: ключ = значение (явный) или expr (автоключ).
   Явный ключ — имя, строка или целое число. Автоключ = max(числовые) + 1, или 0.
   Конфликт ключей — перезапись (последняя запись выигрывает). *)
fields      = [ field { "," field } ] ;
field       = ( Ident | String | Number ) "=" expr   -- явный ключ
            | expr ;                                  -- автоключ

(* if: один end на всю цепочку if/elseif/else. *)
if_expr     = "if" expr "then" block { "elseif" expr "then" block }
              [ "else" block ] "end" ;

(* match: порядок веток важен, проверяется сверху вниз. *)
match_expr  = "match" expr { pattern [ "if" expr ] "->" block } "end" ;
pattern     = "_" | Ident | Number | String | "true" | "false" | "nil"
            | "(" [ pattern { "," pattern } ] ")" ;

lambda      = "\\" "(" params ")" "=" block "end" ;

(* for: числовой (с =) или generic (с in). *)
for_expr    = "for" Ident "=" expr "," expr [ "," expr ] "do" block "end"
            | "for" Ident { "," Ident } "in" expr "do" block "end" ;
loop_expr   = "loop" block "end" ;

block       = { statement } ;
```
