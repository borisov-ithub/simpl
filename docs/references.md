# Simpl — справочник по языку

Версия 0.1.0.

## 1. Общее

Simpl — учебный язык программирования. Синтаксис вдохновлён Lua, семантика — выражениями вместо инструкций (как в Rust и Elixir).

Каждая конструкция в Simpl — **выражение**, у которого есть значение. Программа — это блок выражений, разделённых переводом строки. Значение программы — значение последнего выражения.

Файлы имеют расширение `.spl`. Запуск:

```
simpl program.spl
```

## 2. Лексика

### 2.1 Комментарии

```
-- до конца строки
```

### 2.2 Идентификаторы

Начинаются с буквы или `_`, продолжаются буквами, цифрами и `_`.

### 2.3 Числа

Десятичные. Допускается `_` как разделитель разрядов и `.` для дробной части:

```
42
1_000_000
3.14
```

### 2.4 Строки

В двойных кавычках. Escape-последовательности: `\n`, `\t`, `\"`, `\\`, `\$`.

```
"Привет"
"Строка с \"кавычками\""
```

**Интерполяция:** `$(выражение)` внутри строки подставляет результат выражения. Вложенность `$(...)` внутри `$(...)` не поддерживается.

```
"Сумма: $(2 + 2)"        -- "Сумма: 4"
"Привет, $(name)!"
```

Скобки внутри `$(...)` балансируются, так что `$(f(1, 2))` работает корректно.

### 2.5 Ключевые слова

```
let  if  elseif  else  then  end
for  in  do  loop  break  continue
match  return  and  or  not
true  false  nil
echo  echo.
```

## 3. Переменные и мутабельность

### 3.1 Объявление

```
let x = 1        -- неизменяемая
let ^y = 1       -- изменяемая
```

`^` перед именем — маркер мутабельности. Присваивание без `^` не разрешено.

### 3.2 Присваивание

Только для изменяемых переменных, только с `^`:

```
let ^y = 1
^y = 2           -- ок
y = 3            -- ошибка: неизменяемая или без ^
```

Присваивание неизменяемой переменной — ошибка времени выполнения с подсказкой. Присваивание необъявленной переменной — тоже ошибка.

### 3.3 Область видимости

Блок создаёт новую область видимости: тело функции, тело `if`-ветки, тело цикла, тело `match`-ветки. Переменные внешней области видны внутри, но не наоборот.

### 3.4 Деструктуризация

```
let (a, b) = (1, 2)
let (^x, y) = (10, 20)
```

Элементы кортежа привязываются к именам по порядку. Количество имён и элементов должно совпадать.

## 4. Типы значений

| Тип | Пример | Примечание |
|---|---|---|
| `nil` | `nil` | Отсутствие значения |
| `number` | `42`, `3.14` | Одно число с плавающей точкой |
| `string` | `"abc"` | UTF-8, длина в символах |
| `bool` | `true`, `false` | |
| `tuple` | `(1, "a", true)` | Индексация с 0, фиксированная длина |
| `struct` | `{ name = "Аня" }` | Ассоциативный, ключи — строки |
| `function` | `let f (x) = x end` | |

### 4.1 Кортежи

```
let t = (1, "два", true)
t[0]              -- 1
t[2]              -- true
len(t)            -- 3
```

Пустой кортеж: `()`. Кортеж из одного элемента: `(x,)` — запятая обязательна.

### 4.2 Struct

```
let person = { name = "Аня", age = 12 }
person.name       -- "Аня"
person["age"]     -- 12
```

Автоключи, если элементы перечислены без имён:

```
let arr = { "a", "b", "c" }
arr[0]            -- "a"
arr["0"]          -- "a" (то же самое)
```

Структуры не упорядочены.

## 5. Операторы

От низкого приоритета к высокому:

| Приоритет | Операторы | Ассоциативность |
|---|---|---|
| 1 (низший) | `a if cond else b` | право |
| 2 | `or` | лево |
| 3 | `and` | лево |
| 4 | `not` | унарный |
| 5 | `==` `!=` `<` `<=` `>` `>=` | лево |
| 6 | `++` (конкатенация) | лево |
| 7 | `+` `-` | лево |
| 8 | `*` `/` `%` | лево |
| 9 | унарный `-` | |
| 10 (высший) | вызов `()`, индекс `[]`, поле `.` | лево |

### 5.1 Арифметика

`+`, `-`, `*`, `/`, `%` — только для чисел. Деление или остаток на ноль — ошибка.

### 5.2 Сравнение

`==`, `!=` работают для всех типов. `<`, `<=`, `>`, `>=` — только для чисел.

### 5.3 Логические

`and`, `or`, `not` — короткое замыкание. `nil` и `false` — ложны, всё остальное — истинно.

### 5.4 Конкатенация

`++` соединяет строки. Не-строки преобразуются через `display()` (числа — без `.0` для целых, `true`/`false`, `nil`).

```
"a" ++ 1 ++ true       -- "a1true"
```

### 5.5 Тернарник

```
a if cond else b
```

Сахар над `if`. Цепочка без скобок запрещена — ошибка парсера:

```
1 if a else 2 if b else 3             -- ошибка
1 if a else (2 if b else 3)           -- ок
```

## 6. Условия

```
if cond then expr end
if cond then expr else expr end
if cond then expr elseif cond then expr else expr end
```

`if` — выражение, возвращает значение выбранной ветки. Один `end` на всю цепочку.

## 7. Функции

### 7.1 Объявление

```
let name (params) = body end
```

### 7.2 Анонимная функция

```
\(params) = body end
```

### 7.3 Неявный возврат

Функция возвращает значение последнего выражения в теле. `return` используется для раннего выхода.

```
let f (x) = x + 1 end       -- возвращает x + 1
let g (x) =
    if x > 0 then return "плюс" end
    "ноль"
end
```

### 7.4 Параметры

- Обычные: `let f (a, b) = ... end`.
- Со значением по умолчанию: `let f (a, b = 10) = ... end`. Параметры с default идут после параметров без default. Default вычисляется **при каждом вызове** в окружении вызова, видит предыдущие параметры.
- Сбор остальных: `let f (*rest) = ... end`. `*rest` — последний параметр, получает кортеж всех оставшихся аргументов.

```
let f (a, b = a + 1) = a + b end
f(3)          -- 7 (b = 4)
f(3, 10)      -- 13
```

### 7.5 Арность

Если аргументов меньше, чем обязательных параметров (без default и без `*`) — ошибка. Если больше, чем суммарно без `*` — ошибка.

## 8. Циклы

### 8.1 Числовой for

```
for i = 1, 10 do ... end
for i = 1, 10, 2 do ... end
for i = 10, 1, -1 do ... end
```

Границы включающие. Шаг по умолчанию `1`. Шаг `0` — ошибка.

### 8.2 Итерация по кортежу или struct

```
for v in (1, 2, 3) do ... end
for k, v in { a = 1, b = 2 } do ... end
```

По кортежу: `v` — значение. По struct: `k` — ключ (строка), `v` — значение; порядок ключей не определён.

### 8.3 Бесконечный цикл

```
loop
    ...
    break
end
```

### 8.4 Управление

- `break` — выйти из ближайшего цикла.
- `continue` — перейти к следующей итерации.

## 9. match

```
match value
    pattern -> body
    pattern if guard -> body
    _ -> body
end
```

`match` — выражение, возвращает значение выбранной ветки. Порядок важен: проверяется сверху вниз.

### 9.1 Паттерны

| Паттерн | Совпадение |
|---|---|
| `_` | любое значение |
| `name` | любое значение, привязывает к имени |
| `42` | число 42 |
| `"abc"` | строка "abc" |
| `true` / `false` | булево |
| `nil` | nil |
| `(p1, p2)` | кортеж из двух элементов, оба совпали |

### 9.2 Guard

```
match x
    n if n > 0 -> "плюс"
    n if n < 0 -> "минус"
    _ -> "ноль"
end
```

Guard вычисляется в окружении, где уже привязаны переменные паттерна.

## 10. echo

```
echo expr, expr, ...      -- без перевода строки
echo. expr, expr, ...     -- с переводом строки
```

Инструкция, возвращает `nil`. Аргументы печатаются через пробел. Без аргументов — ошибка парсера.

## 11. Стандартная библиотека

### `len(x)`

Длина строки (в символах), кортежа, struct.

### `type(x)`

Строка: `"nil"`, `"number"`, `"string"`, `"bool"`, `"tuple"`, `"struct"`, `"function"`.

### `str(x)`

Преобразовать в строку (как `display`).

### `num(x)`

Преобразовать в число. Для строки — распарсить. Если не получается — ошибка.

### `range(a, b)`

Кортеж чисел от `a` до `b-1`.

```
for i in range(0, 3) do echo. i end   -- 0 1 2
```

## 12. Ошибки

### 12.1 Ошибки парсера

С указанием строки, столбца, фрагмента и подсказки. Пример:

```
Строка 3:15: ожидался 'end' для конструкции 'if', начатой в строке 2:1, но достигнут конец (встретилось: Eof).
Подсказка: у каждой 'if' должен быть парный 'end'.
```

### 12.2 Ошибки выполнения

С указанием причины и подсказки:

```
Переменная 'x' объявлена как неизменяемая (let x).
Подсказка: используйте let ^x при объявлении, если значение нужно менять.
```

## 13. Что не входит в язык

Для ясности — конструкции, которых в Simpl **нет**:

- `while`.
- `class`, наследование, ООП.
- Метатаблицы, `__index`, `__newindex`.
- Модули, импорты.
- Глобальные переменные (все переменные локальны).
- Пользовательские исключения (`throw`/`catch`).
- Именованные аргументы при вызове.
- Присваивание через индекс или поле (`s.x = 1`, `t[0] = 5`) — пока не поддерживается.
- Вложенная интерполяция `$(... $(...) ...)`.
- Цикл `for` по диапазону с отрицательным шагом в `range()` — используйте числовой `for`.

## 14. Грамматика (EBNF, упрощённо)

```ebnf
program     = { statement } ;
statement   = let | return | break | continue | echo | expr ;
let         = "let" [ "^" ] name [ "(" params ")" ] "=" expr [ "end" ] ;
params      = [ param { "," param } ] ;
param       = [ "*" ] name [ "=" expr ] ;
return      = "return" [ expr ] ;
echo        = ( "echo" | "echo." ) expr { "," expr } ;
expr        = ternary ;
ternary     = or [ "if" or "else" ternary ] ;
or          = and { "or" and } ;
and         = not { "and" not } ;
not         = [ "not" ] comparison ;
comparison  = concat { ( "==" | "!=" | "<" | "<=" | ">" | ">=" ) concat } ;
concat      = add { "++" add } ;
add         = mul { ( "+" | "-" ) mul } ;
mul         = unary { ( "*" | "/" | "%" ) unary } ;
unary       = [ "-" ] postfix ;
postfix     = primary { "(" args ")" | "[" expr "]" | "." name } ;
primary     = number | string | "true" | "false" | "nil"
            | name | "(" tuple_or_group ")" | "{" fields "}"
            | if_expr | match_expr | lambda | for_expr | loop_expr ;
```
